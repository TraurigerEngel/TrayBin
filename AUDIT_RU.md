# Проверка изменений TrayBin 2.1.5

Область изменения: нативное меню Tauri, использование уже существующего HKCU Run-переключателя, метаданные версии и тесты.

Не изменены: чтение и очистка корзины Windows, обработка съёмных томов, фоновый опрос, кэш, значки трея и создание окон (окон нет).

Проверить вручную: галочка меняется при двух кликах; в Диспетчере задач Windows включение/выключение отображается; после перезагрузки приложение запускается только при включённом флажке; двойной экземпляр не создаётся; работа ЛКМ/двойного ЛКМ и очистка не изменены.

Известная особенность: запись относится к конкретному абсолютному пути EXE. При перемещении приложения автозапуск нужно включить заново.

Среда сборки Windows в текущем исполнении недоступна, поэтому всё до проверки на ПК считается Preview.

В полном архиве исправлена опечатка `2.1.3` в проверке Cargo.lock сценария упаковки, добавлена установка зависимостей для чистой среды (`FIRST-BUILD.ps1`). Windows-компиляция из Linux не выполнялась.

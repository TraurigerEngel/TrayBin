# TrayBin v2.0.0 Stable

## Основание релиза

Release Candidate 1 успешно прошёл проверку пользователем в Windows 11: **9 из 9** сценариев.
Также подтверждены **16 из 16** Node.js-тестов, **3 из 3** Rust-тестов, оптимизированная Windows Release-компиляция и создание portable ZIP.

## Состав версии

- Tauri 2 + Rust + HTML/CSS/JavaScript; portable-приложение для Windows 11 x64.
- Тёмно-фиолетовое окно 376×528, Inter, отсутствует светлая рамка.
- Пять оригинальных Classic-иконок в трее и отображение заполненности корзины.
- Одинарный клик открывает корзину, двойной показывает системное подтверждение очистки, ПКМ открывает панель TrayBin.
- Корректное скрытие окна по крестику, завершение по команде «Выход из TrayBin», защита от второго экземпляра.
- Автозапуск по пользовательской настройке, экономичный фоновый опрос.

## Изменения после RC1

**Функциональных и визуальных изменений нет.** Обновлены только номер версии (2.0.0), релизная документация, проверки и имена итоговых артефактов.
Сборка Stable проходит отдельно, не затрагивая каталог `Artifacts\TrayBin_v2.0.0_RC1`.

## Артефакты

- `Artifacts\TrayBin_v2.0.0_Stable\Portable\TrayBin.exe` — оптимизированный portable Release EXE.
- `Artifacts\TrayBin_v2.0.0_Stable\TrayBin_v2.0.0_Stable_Portable.zip` — переносимый архив.
- `Artifacts\TrayBin_v2.0.0_Stable\RELEASE_ARTIFACTS_SHA256.txt` — SHA-256 обоих файлов.

## Замечания

Требуются Microsoft Edge WebView2 Runtime и установленный Inter. EXE не имеет цифровой подписи.
Если ранее был включён автозапуск на тестовый RC1 EXE, после переноса Stable в постоянную папку выключи и снова включи автозапуск, чтобы обновить сохранённый путь.
В Debug-сборках ранее наблюдалось сообщение Chromium Error 1412; утечка не подтверждена.

## Source Archive Packaging (без изменения приложения)

Для этой же версии Stable добавлено создание `TrayBin_v2.0.0_Stable_Source.zip` рядом с portable EXE и ZIP. В архив включаются проверенные исходники и два lock-файла зависимостей. ZIP распаковывается и проверяется по каждому файлу до объявления сборки завершённой; SHA-256 исходного архива записывается в `RELEASE_ARTIFACTS_SHA256.txt`.

Исполняемый Rust-код, HTML/CSS/JS, шрифт Inter, пять Classic-иконок и оформление не менялись.

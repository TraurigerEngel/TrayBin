# TrayBin v2.1.5 — Autostart Menu Stable

Стабильный выпуск TrayBin для **Windows 11 x64**. Приложение работает только в системном трее, без собственных окон и WebView.

## Новое в 2.1.5

- **Нативный переключатель «Автозапуск» с галочкой** в контекстном меню значка (ПКМ).
- Состояние галочки считывается из автозапуска Windows для текущего EXE и синхронизируется после переключения.
- Автозапуск управляется в профиле текущего пользователя; права администратора не нужны.
- При ошибке информация выводится в подсказке значка трея, без дополнительных окон.
- Полный исходный проект теперь можно восстановить через `FIRST-BUILD.ps1` после удаления прежней папки.

## Сохранённые возможности

- Меню ПКМ: **Открыть корзину · Очистить корзину · Автозапуск · Выйти**.
- ЛКМ: открыть корзину; двойной ЛКМ: очистить с системным подтверждением Windows.
- Пять классических значков заполненности и защита от нескольких экземпляров.
- Быстрое обновление раз в 5 секунд, полное раз в 60 секунд, компактный кэш Lean Runtime.
- Исправленная фильтрация обычных съёмных томов (`kind == 3` для учитываемых дисков).

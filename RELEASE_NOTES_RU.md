# TrayBin v2.1.4 — Lean Runtime Stable

Стабильная портативная версия TrayBin для **Windows 11 x64**. Приложение работает исключительно через системный трей, не открывая дополнительных окон или WebView.

## Возможности

- **ПКМ:** «Открыть корзину», «Очистить корзину», «Выйти» — ровно три пункта нативного меню Windows.
- **Один ЛКМ:** открыть системную корзину.
- **Двойной ЛКМ:** очистить корзину с подтверждением Windows.
- Пять оригинальных иконок состояния корзины.
- Защита от запуска нескольких экземпляров.
- Автозапуск, настроенный ранее, продолжает использовать сохранённый путь к EXE.

## Оптимизация Lean Runtime

- Облегчённый кэш состояния: доступность, количество объектов, размер файлов.
- Быстрая проверка изменений — каждые 5 секунд; полная — каждые 60 секунд.
- Съёмные носители исключены из статистики корзины (ограничение текущей реализации).
- Удалено создание WebView-окон; устаревшие UI-исходники сохранены для истории.

## Проверка на Windows 11

- Успешная Release-сборка Rust/Tauri, приложение проверено вручную.
- Регрессионные тесты перед сборкой патча пройдены; числовые показатели CPU и RAM измерены в простое за 5 минут:

| Показатель | Результат |
|---|---:|
| Средняя нагрузка CPU | 0,033% |
| Пиковая нагрузка CPU | 1% |
| Среднее потребление RAM | 18,19 МБ |
| Пиковое потребление RAM | 18,27 МБ |
| Дескрипторы | 242 → 242 |
| Потоки | 4 → 4 |

Показатели получены на одном ПК; на других системах могут отличаться.

## Установка

Скачайте `TrayBin_v2.1.4_Stable_Portable.zip`, распакуйте в постоянную папку и запустите `TrayBin.exe`. Установщик и права администратора не требуются. Для активного автозапуска важен постоянный путь к EXE.

**Контрольный SHA-256 TrayBin.exe:**

`afb7939a0875162019c9de78e3fb0acd3c8b351d03d38d1912ac4cc0188f96bb`

Приложение не подписано цифровой подписью. Проверяйте контрольные суммы перед запуском.

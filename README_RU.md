# TrayBin v2.1.5 — Autostart Menu (Stable)

Лёгкая утилита для корзины Windows 11 x64. Работает исключительно в системном трее, без дополнительных окон и WebView.

## Управление

- **ПКМ:** нативное меню «Открыть корзину», «Очистить корзину», «Автозапуск» (галочка), «Выйти».
- **Один ЛКМ:** открыть корзину Windows.
- **Двойной ЛКМ:** очистить корзину с системным подтверждением Windows.
- Пять оригинальных значков степени заполнения, одиночный экземпляр приложения.

## Автозапуск

Переключатель «Автозапуск» использует запись текущего пользователя в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и учитывает статус `StartupApproved`. Включать автозапуск вручную: он **не включается автоматически** после установки. Галочка синхронизируется с состоянием Windows после изменения. Не требуются права администратора.

При переносе EXE в другую папку прежняя запись в реестре может указывать на старый путь. Откройте TrayBin из нового расположения и переключите пункт автозапуска.

## Производительность

Сохранены оптимизации v2.1.4: быстрый опрос раз в 5 секунд, полный раз в 60 секунд, облегчённый кэш из трёх полей. По одному пятиминутному измерению v2.1.4: средняя нагрузка CPU 0,033%, RAM 18,19 МБ. Это измерение прежней версии, не гарантия для других компьютеров.

Съёмные диски (`kind == 2`) исключены из списка томов корзины; текущая реализация рассматривает только фиксированные диски (`kind == 3`).

## Установка

Скачайте Portable ZIP из [GitHub Releases](https://github.com/TraurigerEngel/TrayBin/releases), распакуйте в постоянную папку и запустите `TrayBin.exe`. Для Windows 11 x64. EXE не подписан цифровой подписью; проверьте SHA-256 из релиза.

## Сборка из исходников

Для новой установки требуются Node.js, Rust MSVC, C++ Build Tools. После распаковки выполните `FIRST-BUILD.ps1`. После первого запуска используйте `BUILD-RELEASE.ps1`; повторная установка зависимостей не нужна.

Стек: Tauri 2, Rust, Windows Shell API. Файлы `ui/` сохранены только для истории; при работе WebView не создаётся.

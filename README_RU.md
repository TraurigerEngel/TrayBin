# TrayBin v2.1.4 — Lean Runtime (Stable)

Минималистичная утилита для корзины Windows 11 x64. Работает только в системном трее, без окон приложения и без WebView.

## Управление

- **ПКМ:** «Открыть корзину», «Очистить корзину», «Выйти» (ровно три пункта).
- **ЛКМ:** открыть корзину Windows.
- **Двойной ЛКМ:** очистить корзину с системным подтверждением Windows.
- Пять классических значков состояния корзины.
- Защита от второго экземпляра, фоновое обновление, сохранение ранее заданного автозапуска.

## Оптимизация 2.1.4

- Компактный кэш: доступность, количество объектов и общий размер.
- Быстрая проверка каждые 5 секунд, полная — каждые 60 секунд.
- Исключение съёмных дисков из расчёта лимита корзины (текущее ограничение реализации).
- В пятиминутном тесте простоя: CPU в среднем 0,033%, RAM 18,19 МБ, дескрипторы 242→242, потоки 4→4. Это один замер, не гарантия для других компьютеров.

## Использование

Скачайте Portable ZIP из GitHub Releases, распакуйте в постоянную папку, запустите `TrayBin.exe`.
Для автозапуска Windows используется ранее сохранённый путь к EXE; перенос файла может потребовать перенастройки.
Приложение не подписано цифровой подписью. Для проверки подлинности используйте SHA-256 из Release.

## Сборка из исходников

Требуются Windows 11 x64, Node.js, Rust MSVC toolchain и C++ Build Tools.
В новой среде установите зависимости согласно `package-lock.json`, затем выполните `npm run test:ui` и `npm run build:release`.
При существующем кэше повторная загрузка зависимостей не нужна.

Стек: Tauri 2, Rust и системный Windows Shell API. Старые файлы `ui/` сохранены в исходниках для истории, но в режиме Tray-Only интерфейс не создаётся.
